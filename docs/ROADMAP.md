# 개발 로드맵

**현재 상태** · 6단계 로컬 실행용 `build/MacTV Custom.app`을 만들었다. 반복 빌드, 서명, macOS 실행과 종료, 전용 데이터 경로와 Bonjour 재연결을 확인했다. 최종 앱의 아이폰 조작·재연결, 외부 재생 중 OSD, LG 직접 DDC와 HDR 확인은 남아 있다. 원본은 MIT 라이선스 `v0.22`(빌드 `32`, `50c9fd90f2f9f373cfdb5aed1a6adac15b369051`)다. [테스트 계획 및 결과](TEST_PLAN.md)

복구용 원본은 형제 폴더 `MacTV-Upstream`의 `v0.22` 체크아웃에 있다. `MacTV-Custom`은 이 커밋의 이력을 이어받으며, 첫 공개 버전 `0.1.0`부터 [브랜치와 배포](RELEASING.md) 흐름을 사용한다.

첫 버전 `0.1.0`의 DMG와 SHA‑256을 GitHub Releases에 게시했다. 태그의 자동 배포 실행 여부는 이후 배포에서 확인한다. [첫 공개 릴리스](https://github.com/Cocomong98/MacTV-Custom/releases/tag/v0.1.0)

`0.2.0`에는 국내 OTT 타일 아이콘, 한국어 첫 연결과 새 앱 아이콘을 적용했다. 같은 인증서로 서명한 연속 버전의 Homebrew 실행 승인 승계는 실기기 검증 항목으로 남아 있다.

## 0. 원본 확보와 무수정 기준선

1. 설치해 사용하는 Mac TV 버전을 확인한다. 해당 버전과 일치하는 태그를 우선 검토하고, 사용할 수 있는 릴리스 또는 커밋을 고른다. 공식 저장소와 고정 버전의 라이선스를 확인한다. [원본 저장소](https://github.com/Arunprakaash/mac-tv) · [릴리스](https://github.com/Arunprakaash/mac-tv/releases)
2. `MacTV-Custom`의 형제 폴더에 원본을 복제한다. 프로젝트 문서가 들어 있는 폴더 위에 바로 복제하지 않는다. 예를 들어 두 폴더의 상위 위치에서 `git clone https://github.com/Arunprakaash/mac-tv.git MacTV-Upstream`을 실행한다.
3. 선택한 태그 또는 SHA를 `git checkout --detach <태그_또는_SHA>`로 고정한다. `git rev-parse HEAD`와 `git status --short`로 버전과 변경 유무를 기록한다. 원본 작업 트리와 사용자 앱·설정은 복구용으로 보존한다.
4. 고정 버전의 `CONTRIBUTING.md`, `Package.swift`, 빌드 스크립트 및 CI를 읽는다. `v0.22`의 빌드 명령은 `./build.sh`다. 테스트 격리 절차, 도구 버전, 종료 코드와 앱 경로는 테스트 계획에 기록한다. [원본 기여 가이드](../CONTRIBUTING.md)
5. 별도 테스트 설정으로 실행하고 동일 Wi-Fi QR 연결, 홈 및 타일, 기존 OTT, 기존 리모컨 탐색·재생·음량을 검증한다. 고정 버전에서 제공하면 별도 데이터 경로 설정을 이용한다. 실기기 확인이 남으면 기준선에 미검증으로 표시한다. [테스트 계획](TEST_PLAN.md)
6. 검증한 원본 이력과 디렉터리 구조를 유지한 작업 사본에 이 문서 세트를 병합한다. 기존 `README.md`, `.gitignore`, `docs/`, `scripts/`의 충돌은 파일별로 비교해 병합한다. 원본 `LICENSE`와 기여 안내를 보존한다. 문서와 원본 백업을 유지한 채 통합 작업 폴더를 `MacTV-Custom`으로 사용한다. 새 작업 폴더에서 기준선 빌드가 재현되는지 확인한다.

기준선 실패 시 먼저 고정 버전의 도구·의존성과 실행 권한을 확인한다. 재현 절차, 첫 오류, 범위와 대안을 기록한다. 기준선 수정이 필요하면 해당 차이를 기능 작업과 별도로 관리한다.

## 단계별 구현

| 단계 | 작업 | 다음 단계 전 확인 | 상태 |
| --- | --- | --- | --- |
| 1 | 국내 OTT 기본 타일 4종 | 공식 경로와 실기기 회귀 통과. 계정별 세부 결과 및 화질 수치 미기록 | 완료 |
| 2 | 유튜브 TV UI, 광고 차단, 홈 타일 | TV 진입·재생 및 유니콘 Pro 테스트 영상 끔·켬 비교 확인. 아이폰 전체 조작과 기존 기능 회귀 확인 대기 | 검증 중 |
| 3 | 내장·외장 화면 밝기 | M1 하드웨어 및 LG BetterDisplay 통합 밝기 조절 확인. 화면별 밝기 프리셋과 정밀 조절을 추가했다. 아이폰·재연결·LG DDC 재확인 필요 | 부분 검증 |
| 4 | 밝기·음량 측면 OSD | 창·macOS 전체화면 패널과 포커스 확인. 아이폰 재생 조작 및 외부 플레이어 확인 중 | 부분 검증 |
| 5 | 아이폰 리모컨 UI 정리 | 밝기·내장 스피커 음량을 한 페이지에 통합. 웹에서 끊김·복구, 실제 스피커 쓰기 확인. 아이폰 실기기 확인 대기 | 부분 검증 |
| 6 | 통합 테스트와 로컬 앱 빌드 | 자동·Mac 실행 검증과 설치·복구 문서 완료. 최종 앱 아이폰 확인 대기 | 부분 검증 |

각 단계에서 요구사항 ID, 변경 파일, 실행한 검증, 결과, 미검증 항목과 복귀 기준을 남긴다. 회귀가 발생하면 직전 정상 버전을 별도 사본에서 재현하고 변경 범위를 좁힌 뒤 재시도한다.
