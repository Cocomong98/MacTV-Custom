# 개발 로드맵

**현재 상태** · 6단계 로컬 실행용 `build/MacTV Custom.app`을 만들었다. 반복 빌드, 서명, macOS 실행과 종료, 전용 데이터 경로와 Bonjour 재연결을 확인했다. 최종 앱의 아이폰 조작·재연결, 외부 재생 중 OSD, LG 직접 DDC와 HDR 확인은 남아 있다. 원본은 MIT 라이선스 `v0.22`(빌드 `32`, `50c9fd90f2f9f373cfdb5aed1a6adac15b369051`)다. [테스트 계획 및 결과](TEST_PLAN.md)

복구용 원본은 형제 폴더 `MacTV-Upstream`의 `v0.22` 체크아웃에 있다. `MacTV-Custom`은 이 커밋의 이력을 이어받으며, 첫 공개 버전 `0.1.0`부터 [브랜치와 배포](RELEASING.md) 흐름을 사용한다.

첫 버전 `0.1.0`의 DMG와 SHA‑256을 GitHub Releases에 게시했다. 태그의 자동 배포 실행 여부는 이후 배포에서 확인한다. [첫 공개 릴리스](https://github.com/Cocomong98/MacTV-Custom/releases/tag/v0.1.0)

`0.2.0`에는 국내 OTT 타일 아이콘, 한국어 첫 연결과 새 앱 아이콘을 적용했다. 같은 인증서로 서명한 연속 버전의 Homebrew 실행 승인 승계는 실기기 검증 항목으로 남아 있다.

첨부된 모니터와 휴대전화 리모컨 그림을 `build/local-icon/MacTV Custom.app`에 적용했다. 공개 배포 전에 이미지의 출처와 배포 이용 조건을 확인한다.

README의 YouTube 광고 필터 설치 안내와 원본 화면 이미지 삽입을 정리했다. 기본 타일을 서비스명·공통 기호·색 배경으로 바꾸고, 기본 파비콘 요청과 앱 번들의 로고 묶음을 제거했다. 공개 이름은 CouchDial로 결정했다. 공개판은 일반 YouTube 웹을 사용하고 기존 이미지 파일을 현재 공개 트리에서 제외한다. 모니터·휴대전화 그림과 기존 타일은 별도 CouchDial Local 빌드에서 사용한다. 공개판 앱 아이콘 재배포 권한과 다음 Cask의 실기기 업그레이드 확인이 남아 있다.

Mac의 설정·제어 센터·팝업과 아이폰 웹 리모컨의 설정·조작 안내를 한국어로 정리했다. 홈에서 순환하는 작품 이미지의 출처와 화면 보호기의 차이는 [UI 명세](UI_SPEC.md)에 기록했다.

## 0. 원본 확보와 무수정 기준선

1. 설치해 사용하는 Mac TV 버전을 확인한다. 해당 버전과 일치하는 태그를 우선 검토하고, 사용할 수 있는 릴리스 또는 커밋을 고른다. 공식 저장소와 고정 버전의 라이선스를 확인한다. [원본 저장소](https://github.com/Arunprakaash/mac-tv) · [릴리스](https://github.com/Arunprakaash/mac-tv/releases)
2. `MacTV-Custom`의 형제 폴더에 원본을 복제한다. 프로젝트 문서가 들어 있는 폴더 위에 바로 복제하지 않는다. 예를 들어 두 폴더의 상위 위치에서 `git clone https://github.com/Arunprakaash/mac-tv.git MacTV-Upstream`을 실행한다.
3. 선택한 태그 또는 SHA를 `git checkout --detach <태그_또는_SHA>`로 고정한다. `git rev-parse HEAD`와 `git status --short`로 버전과 변경 유무를 기록한다. 원본 작업 트리와 사용자 앱·설정은 복구용으로 보존한다.
4. 고정 버전의 `CONTRIBUTING.md`, `Package.swift`, 빌드 스크립트 및 CI를 읽는다. `v0.22`의 빌드 명령은 `./build.sh`다. 테스트 격리 절차, 도구 버전, 종료 코드와 앱 경로는 테스트 계획에 기록한다. [원본 기여 가이드](../CONTRIBUTING.md)
5. 별도 테스트 설정으로 실행하고 동일 Wi-Fi QR 연결, 홈 및 타일, 기존 OTT, 기존 리모컨 탐색·재생·음량을 검증한다. 고정 버전에서 제공하면 별도 데이터 경로 설정을 이용한다. 실기기 확인이 남으면 기준선에 미검증으로 표시한다. [테스트 계획](TEST_PLAN.md)
6. 검증한 원본 이력과 디렉터리 구조를 유지한 작업 사본에 이 문서 세트를 병합한다. 기존 `README.md`, `.gitignore`, `docs/`, `scripts/`의 충돌은 파일별로 비교해 병합한다. 원본 `LICENSE`와 기여 안내를 보존한다. 문서와 원본 백업을 유지한 채 통합 작업 폴더를 `MacTV-Custom`으로 사용한다. 새 작업 폴더에서 기준선 빌드가 재현되는지 확인한다.

기준선 실패 시 먼저 고정 버전의 도구·의존성과 실행 권한을 확인한다. 재현 절차, 첫 오류, 범위와 대안을 기록한다. 기준선 수정이 필요하면 해당 차이를 기능 작업과 별도로 관리한다.

## 홈 상단 영역과 공통 UI · 로컬 구현

Apple TV의 Top Shelf처럼 홈 첫 줄에서 초점을 맞춘 앱에 따라 상단 영역이 바뀌도록 한다. 외부 추천 데이터베이스 없이 한국어 홈과 아이폰 리모컨의 탐색 흐름을 검증한다. [Apple TV 탐색 안내](https://support.apple.com/ko-kr/guide/tv/atvbe55a4b4e/tvos) · [Apple Top Shelf 가이드](https://developer.apple.com/design/human-interface-guidelines/top-shelf)

| 선택한 타일 | 상단 영역 표시 |
| --- | --- |
| OTT·음악·일반 앱 | 앱 이름과 기존 타일 색상을 바탕으로 정적 배경을 표시한다. 위쪽으로 이동하면 상단 영역을 펼치고 **열기**를 제공한다. |
| 로컬 동영상 | 보관함에 있는 가로형 장면이나 포스터를 사용한다. 화면을 채우기에 작은 이미지는 카드로 표시하거나 정적 배경을 사용한다. |
| Steam 게임 | 이미 확보한 게임 이미지를 사용한다. 파일이 없거나 크기가 부족하면 정적 배경을 표시한다. |

### 구현 순서

1. `add-home-top-shelf` 브랜치에서 `TopShelfView`와 `HomeFocus`를 함께 수정한다. 첫 줄 좌우 이동, 위로 확장, 뒤로 복귀를 연결한다. 추천 작품 검색 버튼을 정리하고 **열기**는 기존 앱 실행 경로를 사용한다.
2. TVmaze와 Apple Music 차트에 연결하는 상단 영역 코드를 정리한다. 다른 서비스 작품을 섞는 표시와 편성 지역·언어 설정도 함께 정리한다. 기존 동영상·Steam 이미지 경로를 사용하고, 전체 화면 표시에서는 이미지의 실제 픽셀 크기를 화면과 비교한다.
3. 화면 보호기가 기존 상단 추천 캐시에 의존하는 경로를 정리한다. 이전에 **상단 추천**을 선택한 경우 움직이는 색상으로 전환한다. 기존 추천 캐시와 사용자 동영상·사진은 보존한다.

4. Mac 설정·제어 센터·팝업·재생 안내와 아이폰 리모컨에 공통 여백, 대비, 초점 표시를 적용했다.

### 완료 기준

- 키보드와 아이폰 리모컨 모두 첫 줄에서 좌우로 이동하면 배경이 해당 앱을 따라 바뀐다. 위로 올라가 **열기**를 선택하고 홈으로 돌아오면 해당 타일에 초점이 복귀한다.
- MacBook 내장 화면과 4K 외장 화면의 창 모드·전체 화면에서 글자와 정적 배경이 선명하다. 로컬 이미지가 없거나 읽을 수 없어도 배경과 앱 열기가 정상 동작한다.
- 인터넷 연결 없이도 상단 영역이 표시된다. 같은 Wi-Fi에서 QR 연결·재연결, 기존 OTT 재생·일시 정지, 내장 스피커 음량과 화면 보호기 진입·복귀를 확인한다. OTT 재생은 인터넷이 연결된 상태에서 확인한다.
- 로컬 빌드와 실기기 검증을 마친 뒤 기존 주간 배포 절차에 반영한다. 결과는 [테스트 계획](TEST_PLAN.md)에 기록한다.

로컬 빌드와 자동 검증을 완료했다. MacBook 화면과 4K 외장 화면에서의 표시, 아이폰 QR 재연결과 실제 OTT 재생·음량은 실기기 확인이 남아 있다.

OTT 자체 미리보기는 공식 제공 경로와 재사용 조건을 확인한 뒤 별도 작업으로 검토한다.
