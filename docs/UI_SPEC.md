# UI 명세

Apple TV의 거실 화면과 방향키 탐색을 참고해 Mac 홈과 공통 화면을 구성한다. 아이폰에서는 QR 웹 리모컨을 사용한다.

## Mac TV 홈

- 웨이브·왓챠·티빙·라프텔 기본 타일을 기존 기본 앱 뒤와 **앱 추가**·**설정** 앞에 배치한다. 기존 프로필의 숨김, 고정 및 저장 순서를 적용한다.
- 기본 서비스 타일은 위쪽에 서비스별 색의 그라데이션과 영상·음악·플레이어 공통 기호를 표시한다. 아래쪽의 어두운 배경 위에 일반 글꼴로 서비스명을 표시한다. 기본 타일은 이미지를 내려받거나 기존 파비콘 캐시를 읽지 않는다. 사용자가 추가한 타일의 아이콘은 기존 방식으로 표시한다.
- 홈 타일은 방향키 초점에 맞춰 커지고 살짝 올라오며, 위쪽 조명과 아래쪽 그림자로 강조한다. 모션 감소 설정에서는 이동과 기울임을 줄인다.
- 공개판의 YouTube 타일은 일반 YouTube 웹을 열고 프로필의 웹 플레이어 설정을 따른다. 새 경로에서 아이폰 방향키와 재생 조작 범위를 확인한다.
- 재생 종료 또는 홈 동작 후 직전 타일로 초점이 돌아오는지 검증한다. 오류 화면에서 재시도와 홈 복귀가 가능해야 한다.

### 홈 상단 영역

- 첫 줄에서 타일을 선택하면 해당 앱의 이름과 색상으로 상단 영역을 표시한다. 위 방향키로 올라가면 **열기**에 초점이 맞춰지고, 선택하면 해당 타일의 기존 경로로 앱을 연다. 뒤로 또는 아래 방향키로 해당 타일에 돌아간다.
- 로컬 동영상과 Steam의 기존 이미지 파일을 사용할 수 있다. 가로형 이미지의 실제 픽셀 크기가 현재 창의 출력 픽셀 크기 이상이면 배경을 채운다. 크기가 작은 이미지는 카드로 표시하고, 이미지가 없으면 앱 색상으로 배경을 채운다.
- 홈 상단 영역은 외부 추천 데이터베이스나 차트를 조회하지 않는다. 화면 보호기는 macOS 항공 영상, 지정한 사진 폴더 또는 움직이는 색상을 사용한다. 저장된 **상단 추천** 옵션은 움직이는 색상으로 해석한다. 항공 영상은 다운로드된 파일을 우선 사용한다.

## Mac 공통 화면

설정, 제어 센터, 팝업과 재생 안내는 공통 여백과 모서리, 어두운 반투명 패널, 읽기 쉬운 보조 문구를 사용한다. 방향키로 선택한 항목의 초점은 밝은 테두리와 색상으로 구분한다. 모션 감소 설정에서는 제어 센터 전환 애니메이션을 줄인다.

## 아이폰 리모컨

Mac의 시작 안내, QR 연결과 연결 설정, 아이폰 브라우저의 수동 연결 및 연결 오류 안내는 한국어로 표시한다. Mac과 아이폰에서 각 운영체제의 기본 글꼴을 사용한다.

같은 Wi-Fi에서 첫 연결 QR은 Mac의 IPv4 주소를 연다. 수동 연결은 QR 아래의 주소를 Safari에 입력하고 Mac 화면의 6자리 연결 코드로 완료한다. 리모컨은 연결 후 Mac의 `.local` 주소가 응답하면 기존 방식으로 이동한다. `.local`에 응답이 없으면 IPv4 주소에서 계속 작동한다.

Mac 설정·제어 센터·일반 알림과 웹 리모컨의 조작 버튼·설정·주요 오류는 한국어로 표시한다. OTT 화면, 작품명, 기기명, 운영체제나 외부 앱의 상세 오류는 원본 언어가 표시될 수 있다.

방향키·선택·뒤로·홈·재생과 QR 연결 흐름을 유지한다. 조작 버튼과 설정 팝업은 터치 영역, 배경 대비와 키보드 초점 표시를 공통으로 적용한다. 신뢰 리모컨의 **설정 → 화면 및 사운드**에서 내장 스피커 음량, 화면별 밝기, 재생 디스플레이를 한곳에서 조절한다. 화면에서 읽은 값이 있을 때만 밝기 슬라이더를 조작할 수 있다. BetterDisplay를 사용하는 외장 화면은 이름 옆에 `(BetterDisplay)`를 표시하고 BetterDisplay의 일반 밝기와 같은 값을 표시한다.

각 디스플레이에 0·25·50·75·100% 버튼을 표시한다. 버튼을 터치하면 해당 값이 적용된다. 슬라이더를 짧게 터치하면 가장 가까운 버튼 값이 선택되고, 슬라이더를 약 350ms 누른 뒤 드래그하면 1% 단위 값을 미리 본다. 손을 떼면 해당 디스플레이에 한 번 적용한다. 스크롤이나 터치 취소로 제스처가 중단되면 이전 값으로 돌아온다.

신뢰 리모컨 메인 상단의 **화면 밝기** 버튼은 기존 화면 및 사운드 설정의 밝기 구역을 바로 연다. **앱 전체 화면** 버튼을 누르면 Mac 앱 창을 전체 화면과 창 모드 사이에서 전환한다. 버튼은 실제 창 상태를 반영하고 전환이 끝날 때까지 입력을 잠근다. 전용 TV 설정을 켠 상태에서 리모컨으로 창 모드로 전환하면 현재 실행 중에는 창 모드를 유지하고, 앱을 다시 실행하면 저장된 전용 TV 설정을 사용한다.

| 표시 이름 | 조작 | 상태 문구 예시 |
| --- | --- | --- |
| LG 32UP830 · 외장 디스플레이 | 밝기 0–100% | 연결되지 않음, 현재 값 확인 불가 |
| MacBook Air · 내장 디스플레이 | 밝기 0–100% | 현재 값 확인 불가 |
| MacBook Air · 내장 스피커 | 음량 0–100%. 드래그를 놓을 때 적용 | 음소거, 현재 출력 장치, 슬라이더 비활성 |

음량 슬라이더는 Mac의 기본 출력이 내장 스피커일 때 시스템 음량을 제어한다. 다른 출력이 활성일 때는 장치 이름을 표시하고 슬라이더를 잠근다. IINA 재생 중 기존 음량 버튼은 IINA 플레이어 음량을 제어한다. 연결이 끊기면 슬라이더를 잠그고 연결 복구 후 확인값을 표시한다. 드래그 중에는 값을 미리 보고, 놓았을 때 읽어 확인한 수치를 표시한다.

## 화면 측면 OSD

| 항목 | 밝기 | 음량 |
| --- | --- | --- |
| 표시할 화면 | 조절 대상 디스플레이 | 콘텐츠를 재생하는 디스플레이 |
| 배치 | 왼쪽 중간 세로 게이지 | 오른쪽 중간 세로 게이지 |
| 표시 요소 | 밝기 아이콘, 게이지, 확인된 값 | 음량 아이콘, 게이지, 확인된 값 또는 음소거 |

반투명 배경과 흰색 게이지로 표시한다. 조작한 값이 확인되면 표시하고 마지막 조작 후 약 2초 뒤 숨긴다. 같은 화면과 항목을 연속 조작하면 기존 패널의 값과 타이머를 갱신한다. 콘텐츠 재생이 없을 때 음량은 Mac TV 창의 화면에 표시한다. 볼륨을 장치에서 제어하면 `TV`, 음소거 시 한국어 상태를 표시한다.

Mac TV 내장 재생과 외부 플레이어의 전체화면에서 영상, 자막, 방향키 입력 및 기본 OSD와의 중복 여부를 확인한다.
