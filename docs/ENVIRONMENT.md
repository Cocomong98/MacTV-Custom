# 개발 및 사용 환경

## 사용자 확인 구성

| 항목 | 구성 |
| --- | --- |
| 메인 Mac | MacBook Air 13형 M1 |
| 외장 모니터 | LG 32UP830, 카멜마운트 이동식 거치대에 장착 |
| 화면 배치 | 내장 화면과 외장 화면을 확장 모드로 독립 사용 |
| 음향 출력 | MacBook 내장 스피커 |
| 리모컨 | 아이폰, 기존 QR 웹 리모컨 흐름 유지 |
| 연결 | 동일 Wi-Fi/LAN |
| 유튜브 | YouTube Premium 미사용. 기존 브라우저에서 유니콘 Pro와 함께 광고 없이 시청 중이라고 사용자가 보고함 |
| 개발 비용 | 추가 결제, 유료 API, 유료 Apple Developer 멤버십 없이 진행 |

## 기준선에서 기록할 항목

- Mac의 macOS 버전·빌드, 아이폰 모델·iOS·Safari 버전, 현재 설치한 Mac TV 버전과 검증할 원본 SHA.
- Mac과 LG 사이의 실제 포트, 케이블, 허브 또는 어댑터, 모니터 입력과 DDC/CI 관련 설정, 확장·미러링 상태와 주 디스플레이.
- 실제 기본 오디오 출력 장치, 음소거 상태, 내장·외장 화면 이름과 연결 해제·재연결 후 식별 상태.
- 기존 브라우저 및 유니콘 Pro 버전과 활성 프로필, 필요한 경우 필터와 예외 적용 범위. 로그인 정보는 기록에서 제외한다.
- QR로 접속하는 네트워크와 방화벽·로컬 네트워크·손쉬운 사용 권한 상태. 게스트 Wi-Fi 격리, VPN, 동일 LAN이지만 접속이 안 되는 경우도 확인한다.
- `sw_vers`, `swift --version`, `xcode-select -p`로 빌드 환경을 기록한다. Node와 브라우저는 해당 버전의 웹 테스트에 필요한 경우 확인한다.

## 호환성 상태

기준선 실행 환경은 arm64, macOS 27.2.1(26B131), Xcode 27.2(27B52), Apple Swift 6.4.2, Node.js 26.12.1이다. 웹 레이아웃 테스트에는 설치된 Google Chrome을 사용했다. 원본 `v0.22`는 macOS 14 이상을 대상으로 한다. 검증 내역은 [테스트 계획](TEST_PLAN.md)과 [원본 기여 가이드](../CONTRIBUTING.md)를 참고한다.

MacBook Air M1과 LG 32UP830은 USB‑C ↔ USB‑C로 직결되어 있다. macOS에서 두 화면은 미러링 없이 온라인이고, LG는 `LG HDR 4K`(3840×2160)로 표시된다. BetterDisplay 5.2.1과 m1ddc `9d75fb6`으로 LG DDC 조회를 시도했으나 응답을 받지 못했다. HDR 활성 상태와 모니터 설정은 미확인이다. 전체화면 OSD는 후속 단계에서 검증한다.
