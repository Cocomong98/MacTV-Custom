# 요구사항 R01–R16

아래 ID와 범위는 승인된 기준이다. 각 요구사항의 상태는 구현과 검증 결과에 따라 갱신한다.

| ID | 요구사항 | 상태 | 완료 기준 |
| --- | --- | --- | --- |
| R01 | 동일 네트워크 연결 유지 | 확정 | 같은 신뢰 Wi-Fi/LAN에서 기존 QR을 스캔해 웹 리모컨에 연결하고 재연결한다. |
| R02 | Mac TV 홈과 상단 영역 | 로컬 구현·자동 검증 통과 · 실기기 확인 대기 | 첫 줄 선택에 맞춰 외부 추천 DB 없이 상단 영역을 표시하고, 앱 열기와 홈 복귀 시 타일 초점을 유지한다. |
| R03 | 기존 해외 OTT 유지 | 확정 | 기준선에 있던 해외 OTT가 기존 경로에서 열리고 기존 재생 동작을 유지한다. |
| R04 | 국내 OTT 4종 추가 | 기본 타일 구현 · 실기기 정상 보고 | 웨이브, 왓챠, 티빙, 라프텔을 기본 타일로 등록하고 각각 공식 플레이어로 이동한다. 로그인, 재생, 조작 가능 범위를 서비스별로 기록한다. |
| R05 | TV용 유튜브 UI | 개인용 로컬판에 유지 · 공개판은 일반 YouTube 웹 | 큰 타일과 방향키 중심의 YouTube TV(Leanback) 이용 흐름에서 탐색·선택·재생·뒤로 가기가 동작한다. |
| R06 | 유튜브 광고 차단 | 유니콘 Pro 끔·켬 비교 통과 · 테스트 영상 | YouTube Premium 없이 선택한 TV 시청 경로의 광고 차단과 정상 재생을 비교 검증한다. |
| R07 | 유튜브 메인 화면 타일 통합 | 판별 경로 구현 · 공개판 실기기 확인 대기 | 공개판은 일반 웹, 개인용 로컬판은 기존 TV 화면을 열고 아이폰 리모컨에서 홈으로 돌아온다. |
| R08 | 맥북 내장 화면 밝기 조절 | M1에서 읽기·쓰기 확인 · 아이폰 검증 중 | 아이폰에서 MacBook Air 내장 화면 밝기를 조절하고 가능한 경우 시스템 값을 읽는다. |
| R09 | LG 32UP830 밝기 조절 | 직접 DDC 조회 무응답 · BetterDisplay 일반 밝기 적용 | 실제 연결 구성에서 하드웨어 밝기 변경과 읽기 가능 범위를 확인한다. 불가하면 원인과 대체 방식의 상태를 기록한다. |
| R10 | 디스플레이별 독립 밝기 제어 | 화면별 UUID 적용 · 실기기 검증 중 | 한 화면을 조절해도 다른 화면의 밝기는 유지된다. 화면 재연결 후에도 각 조작 대상이 올바르다. |
| R11 | 맥북 내장 스피커 음량 제어 | 기존 버튼 유지 · 신뢰 리모컨 음량 슬라이더 구현 | 아이폰에서 내장 스피커 음량을 조절하고 실제 출력과 표시가 일치한다. |
| R12 | 밝기 조절 측면 OSD | 구현 · macOS 전체화면 검증 | 밝기 변경 대상 화면 측면에 값이 표시되고 재생 흐름을 유지한다. |
| R13 | 음량 조절 측면 OSD | 구현 · macOS 전체화면 검증 | 콘텐츠 화면 측면에 음량이 표시되고 재생 흐름을 유지한다. |
| R14 | 아이폰 단일 리모컨 유지 | 확정 | 같은 QR 웹 리모컨으로 홈, 콘텐츠, 화면별 밝기, 음량을 제어한다. |
| R15 | Apple Developer 유료 계정 미사용 | 임시 서명 로컬 빌드·재실행 통과 | 유료 멤버십과 배포용 서명 없이 개인 Mac에서 로컬 빌드한 앱을 실행하고 필요한 권한을 확인한다. |
| R16 | Bluetooth 연결 | 개발 제외 | Bluetooth 페어링이나 권한이 추가 기능의 동작 조건이 되지 않는다. |

## 구현 조건

- 국내 OTT는 공식 웹 플레이어를 이용한다. 로그인 유지, DRM, 최대 화질, 방향키와 전체화면은 서비스별 검증 사항이다.
- 유니콘 Pro 연동은 후보이며 TV 모드에서 광고 차단과 재생이 유지되는지가 요구사항이다. 브라우저에서의 기존 사용 경험은 TV 모드 호환성의 근거로 간주하지 않는다.
- R09의 소프트웨어 감광 대안은 하드웨어 밝기 조절과 구분하고, 요구사항 충족 여부는 [결정 기록](DECISIONS.md)에 남긴다.
- OSD의 정확한 좌우 위치, 색상과 노출 시간은 [UI 명세](UI_SPEC.md)의 초안이며 시청 중 실사용으로 검증한다.
