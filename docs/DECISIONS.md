# 결정 기록

## 이전 대화에서 확정한 사항

| 결정 | 근거 및 적용 범위 |
| --- | --- |
| 원본 Mac TV 기반으로 개발 | 홈과 기존 OTT·리모컨을 보존하면서 사용자 장비에 필요한 기능을 추가한다. |
| 동일 Wi-Fi/LAN과 기존 QR 웹 리모컨 유지 | 아이폰 하나로 조작한다. Bluetooth 연결 기능 개발은 제외한다. |
| 공식 국내 OTT 타일 4종 추가 | 웨이브·왓챠·티빙·라프텔을 기존 홈에서 시작한다. 서비스별 동작은 확인한다. |
| 유튜브 TV 이용 흐름과 광고 차단을 요구 | Premium 없이 기존 브라우저에서 쓰던 시청 경험을 홈 타일과 통합한다. 기술 선택은 보류한다. |
| 화면별 밝기, 내장 스피커 음량, 측면 OSD | 내장·외장 확장 환경에서 각 대상을 독립 조작한다. |
| 유료 개발자 멤버십 없이 로컬 빌드 | 개인 Mac에서의 실행을 기준으로 한다. 추가 유료 API나 외부 서버에 의존하지 않는다. |
| 개발 문서 분리 | `AGENTS.md`를 진입점으로 사용하고 작업별로 필요한 명세를 참조한다. |

## 확보 또는 검증 뒤 결정할 사항

| 항목 | 현재 상태 | 결정 근거 |
| --- | --- | --- |
| 원본 버전과 도입 위치 | 공식 저장소 확인, SHA 미고정 | 사용자 기존 버전, 무수정 빌드, 권한, 문서 병합 충돌 |
| 유튜브 통합 방식 | 공식 `/tv`를 내장 WebKit에서 여는 기존 타일을 사용. 외부 브라우저 설정으로 일반 화면이 열리는 문제는 타일 경로에서 수정 | 리모컨 조작과 홈 복귀, 유니콘 Pro를 통한 TV 재생 광고 차단 비교 |
| 내장 밝기 경로와 LG DDC/CI | 내장 DisplayServices의 읽기·쓰기·원상 복구 확인. 외장은 설치된 BetterDisplay의 직접 DDC API를 옵션으로 연결 | USB‑C 직결 LG에서 DDC 조회 무응답. 쓰기와 재연결 확인 대기 |
| 외장 밝기 대체 경로 | 직접 DDC 조회가 실패하면 BetterDisplay의 일반 밝기와 같은 `brightness`를 사용한다. LG에서 소프트웨어 밝기 100%는 통합 눈금 50%였고, 사용자가 통합 눈금 75%에서 실제 화면이 더 밝아지는 것을 확인했다. | 색상·HDR 영향, 재연결 확인 |
| 측면 OSD 상세 | 밝기는 조절 화면 왼쪽, 음량은 재생 화면 오른쪽에 표시. 입력을 받지 않는 패널을 사용하며 약 2초 후 닫는다. | 아이폰·외부 재생 중 시인성, 자막과 기본 OSD 중복 |
| 로컬 서명과 원본 업데이트 설정 | `MacTV Custom.app`에 별도 번들 ID·앱 데이터·키체인 서비스를 적용한다. 커스텀 빌드는 수동으로 교체하고 원본 업데이트와 원본 사용 통계 전송을 사용하지 않는다. | 임시 서명 또는 선택한 로컬 인증서로 재설치한 뒤 OS 권한 확인 |

새 결정은 날짜, 관련 요구사항 ID, 선택한 방식, 근거가 된 검증, 남은 제약과 복귀 방법을 함께 기록한다.
